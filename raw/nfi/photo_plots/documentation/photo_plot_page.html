Land Cover Classification

The Land Cover Classification Scheme is used to describe current vegetated and non-vegetated land cover in NFI photo plots. The documentation for this scheme is now included in the Photo Plot Data Dictionary.

Land Use Classification

The Land Use Classification Scheme is used to describe current land use in NFI photo plots. The documentation for this scheme is now included in the Photo Plot Data Dictionary.
