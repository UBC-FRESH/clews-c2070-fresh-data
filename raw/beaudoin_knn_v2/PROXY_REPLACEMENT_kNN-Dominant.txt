Proxy replacement for missing kNN-Dominant.tar (legacy SAFORAH 1.0)
======================================================================

Discovery date        : 2026-08-11
Probed by             : UBC FRESH / CLEWs-C2070 forestry data maintainers
Replacement rationale : The SAFORAH 1.0 archive `kNN-Dominant.tar`
                        (formerly at http://tree.pfc.forestry.ca/kNN-Dominant.tar)
                        permanently returns HTTP 302 to
                        http://nfis.org/notfound_bi.html and is NOT
                        advertised on the legacy index page
                        (http://tree.pfc.forestry.ca/, audited 2026-08-11,
                        lists exactly 8 grouped kNN-*.tar archives, none
                        of which is named kNN-Dominant.tar).

Lineage gap
-----------

  Legacy kNN-Dominant.tar (302 / placeholder):
    Mounted on the SAFORAH 1.0 filesystem as a tar placeholder pointing
    at http://nfis.org/notfound_bi.html. No actual tar payload exists
    anywhere on the legacy server or its mirrors; the request always
    redirects to a 621-byte HTML stub (Last-Modified 2015-07-22). The
    legacy index page never advertised kNN-Dominant.tar; the pointer
    originated in an external InVEST-style data dictionary and never
    pointed at a real archive.

  SAFORAH 2.0 ca_kNN_DominantGenus_250m_r (this directory):
    Single-layer WMS visualization of “dominant genus” for the 2001
    base year mosaic. Different lineage: derived from the same NFI
    ground + photo plots but processed through the SAFORAH 2.0
    publication pipeline (MapServer 6.4.1 serving 24 named layers).
    Format is PNG via WMS GetMap, NOT the per-species GeoTIFF members
    that Beaudoin bundles. Do not substitute byte-for-byte for the
    missing tar; record as proxy only.

Reproducing this directory
--------------------------

  GetCapabilities:
    curl -sL -H "User-Agent: $UA" \
      "https://nfi.nfis.org/mapserver/cgi-bin/nfis-kNN.cgi?SERVICE=WMS&VERSION=1.3.0&REQUEST=GetCapabilities" \
      -o WMS_GetCapabilities_nfis-kNN.full.xml

  GetMap (PNG, 2048, Canada bbox):
    BASE="https://nfi.nfis.org/mapserver/cgi-bin/nfis-kNN.cgi"
    curl -sL -H "User-Agent: $UA" \
      "${BASE}?SERVICE=WMS&VERSION=1.3.0&REQUEST=GetMap&LAYERS=kNN_DominantGenus_250m&CRS=EPSG:4326&BBOX=-140,40,-50,80&WIDTH=2048&HEIGHT=2048&FORMAT=image/png&STYLES=default" \
      -o ca_kNN_DominantGenus_250m_canada_2048.png

  GetLegendGraphic:
    curl -sL -H "User-Agent: $UA" \
      "${BASE}?SERVICE=WMS&VERSION=1.3.0&REQUEST=GetLegendGraphic&SLD_VERSION=1.1.0&LAYER=kNN_DominantGenus_250m&FORMAT=image/png&STYLE=default" \
      -o ca_kNN_DominantGenus_250m_legend.png

Residual gaps
-------------

  (a) Bulk GeoTIFF data for the dominant-genus attribute are NOT publicly
      downloadable from SAFORAH 2.0 in tar/zip form. Bulk end-users must
      approach NRCan CFS Pacific directly to negotiate a data transfer
      agreement (mailto:alex.song@canada.ca).

  (b) WMS images are coloured visualizations; the underlying categorical
      raster (each pixel = dominant-genus integer code) is held back
      server-side. Anyone needing the raw raster must contact the
      Data Manager.

  (c) The same SAFORAH 2.0 catalogue exposes a parallel `_2011` vintage
      (e.g. ca_kNN_DominantGenus_250m_r_2011) for the same layer with
      2011 base-year mosaics, also WMS-only. Not acquired this turn.
